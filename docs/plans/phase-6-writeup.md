# Phase 6 — 논문 작성·제출

상태: ⬜ 미완료

## 목표

남에게 그대로 보여줄 수 있는 한 벌(논문 + 재현 패키지 + AI/나의 판단 3줄)로 묶는다.

## 할 일

- [ ] 본문 배치 — 서론 · 방법 · 결과 · 논의 순서
- [ ] 참고문헌 목록을 본문 뒤에 배치, 표기 형식 통일
- [ ] 본문 인용 문헌이 목록에 모두 있는지 대조
- [ ] 초록 작성 (마지막에) — 문제의식·방법·결과 모두 포함, 약 10줄
- [ ] 표지 — 제목·작성자·작성일
- [ ] 재현 방법 작성 — 어떤 데이터를 어디서 받아 무엇을 실행하는지
- [ ] 원자료·실행 스크립트를 폴더로 정리
- [ ] AI에게 맡긴 일과 직접 판단한 일 3줄로 구분
- [ ] 전체를 ZIP 하나로 묶고, 다른 폴더에서 풀어 빠진 파일 확인
- [ ] 미완성 표시·자리표시자 남아 있지 않은지 최종 점검
- [ ] URL을 제출한다면 시크릿 창에서 로그인·인증 없이 열리는지 확인

## 산출물

- 완성 논문 1편
- 재현 패키지 ZIP (원자료 + 스크립트 + 절차)
- AI와 나의 판단 3줄

## 완료 기준

- 제출물이 한 개의 ZIP 파일이다.
- 초록에 문제의식·방법·결과가 모두 들어 있다.
- 미완성 표시나 자리표시자가 없다.

## 주의

- 분량은 기준이 아니다. 가설·근거·데이터·결론이 이어지면 짧아도 논문이다.
