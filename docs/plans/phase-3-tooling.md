# Phase 3 — 실험 도구 개발

상태: ⬜ 미완료

## 목표

클라이언트·서버 사이에서 협상 필드를 통제된 방식으로 조작하는 Fault Injector와, 결과를 자동 수집·기록하는 하네스를 만든다.

## 할 일

- [ ] Fault Injector 골격 — 클라이언트/서버 사이 중간자 형태로 TLS 레코드 계층 가로채기
  - 도구: Python(scapy 또는 `s_client`/`s_server` 저수준 후킹), 필요 시 mitmproxy류 확장
- [ ] 결함 유형 1 — 그룹 목록 조작: `supported_groups`/KEX 목록에서 하이브리드 그룹 제거·순서 변경
- [ ] 결함 유형 2 — 컴바이너 바인딩 위반: 두 성분(고전/PQ) 중 하나만 실제 값, 나머지는 조작 값
- [ ] 결과 수집 하네스 — 협상 결과 그룹, 감사 도구 탐지 여부, 핸드셰이크 성공/실패를 구조화된 원자료로 저장
- [ ] 짧은 확인 스크립트 — 조작이 실제로 반영됐는지 검증 (도구 자체 버그와 실험 결과 구분)

## 산출물

- 결함 주입 스크립트 (재현 패키지에 포함)
- 결과 수집·기록 하네스
- 도구 동작 확인 스크립트

## 완료 기준

- 결함 유형 2종을 3개 구현체 각각에 적용할 수 있다.
- 실행 1회당 관측 지표 3종이 자동으로 원자료에 기록된다.

## 주의

- 조작이 반영됐는지 먼저 검증한다 — 도구가 조용히 실패하면 "결함 없음"으로 오판할 수 있다.
