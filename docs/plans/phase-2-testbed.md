# Phase 2 — 실험 환경 구축

상태: ⬜ 미완료

## 목표

하이브리드 KEM을 구현한 독립 코드베이스 3종을 로컬에 빌드하고, 정상 하이브리드 핸드셰이크가 성립하는 기준선(baseline)을 확보한다.

## 할 일

- [ ] OpenSSL + oqs-provider 빌드 (CVE-2026-2673 대상 라인 확인)
  - 하이브리드 그룹(예: X25519MLKEM768)으로 `s_server`/`s_client` 핸드셰이크 성공 확인
- [ ] BoringSSL 빌드
  - 하이브리드 그룹(예: X25519Kyber768)으로 핸드셰이크 성공 확인
- [ ] OpenSSH 하이브리드 KEM 빌드/설정
  - sntrup761x25519-sha512 등으로 SSH 핸드셰이크 성공 확인
- [ ] 각 구현체의 버전·커밋 해시·빌드 옵션 기록 (재현용)
- [ ] 감사·로깅 경로 확인 (SSLKEYLOGFILE, `s_server -state`, `sshd -vvv`, Wireshark 캡처)

## 산출물

- 빌드된 3개 구현체와 버전/빌드 옵션 기록
- 각 구현체의 정상 하이브리드 핸드셰이크 baseline 로그

## 완료 기준

- 3개 구현체 모두 조작 없이 하이브리드 핸드셰이크가 성립한다.
- 각 구현체에서 협상 결과 그룹을 로그로 관측할 수 있다.

## 주의

- 버전을 정확히 고정한다 — 결함이 특정 버전에만 있을 수 있으므로 재현에 필수.
