# Phase 5 — 결과 분석

상태: ⬜ 미완료

## 목표

원자료를 정리해 가설을 판단한다. 핵심 질문: 협상 로직 결함으로 인한 하이브리드 PQ 다운그레이드가 특정 라이브러리의 우연한 버그인가, 여러 구현체에 걸친 일반적 패턴인가.

## 할 일

- [ ] 원자료를 구현체별 비교표/그래프로 정리
- [ ] 가설대로 나온 부분과 다르게 나온 부분 구분
- [ ] 각 판단의 근거가 원자료의 어느 값인지 명시
- [ ] 다르게 나온 부분마다 이유 후보 검토 (데이터로 확인 가능한 것부터)
- [ ] 필요 시 조건 바꿔 재실행 또는 가설 문장 수정 (수정 시 전/후 모두 기록)
- [ ] 최종 결론 작성 (한 문단 이상)
- [ ] 한계 작성 — 이 연구로 말할 수 없는 것

## 산출물

- 구현체별 결과 비교표/그래프
- 해석과 가설 판단
- 가설을 고쳤다면 그 과정
- 한계 서술

## 완료 기준

- 가설과 다른 결과가 빠짐없이 실려 있다.
- 결론이 원자료에 없는 주장을 하지 않는다.
- 다르게 나온 이유로 검토한 가능성이 하나 이상 적혀 있다.

## 주의

- 판단은 직접 한다. AI에게는 요약만 맡기고 결론을 대신 쓰게 하지 않는다.
