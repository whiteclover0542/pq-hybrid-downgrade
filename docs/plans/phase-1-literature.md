# Phase 1 — 문헌 조사

상태: ⬜ 미완료

## 목표

가설을 뒷받침하는 선행 연구를 찾아 실존을 검증하고, 기준 사례인 CVE-2026-2673을 원문 수준으로 이해한다. "이미 알려진 것"과 "이 연구가 새로 주장하는 것"을 나눈다.

## 할 일

- [ ] 하이브리드 컴바이너 다운그레이드 저항성 관련 선행 연구 목록화
  - Bhargavan et al.의 다운그레이드 저항성 정의
  - "Transcript-Bound Combiners for Downgrade-Resilient Hybrid PQ Key Establishment" (2026-09)
- [ ] 각 문헌 실존 검증 — 제목 검색, 저자·연도 확인, 초록 확인
- [ ] 문헌마다 "가설의 어느 부분을 뒷받침하는지" 한 줄 연결
- [ ] 실물이 없거나 내용이 다른 문헌은 제외하고 그 사유 기록
- [ ] CVE-2026-2673 상세 분석 — OpenSSL security advisory 원문, 영향 버전, 결함 메커니즘
- [ ] 배경 CVE 3건(FreeRDP·Cisco·NGINX)의 NVD 항목 재확인

## 산출물

- 참고문헌 목록 (저자·연도·출처, 가설 연결 한 줄, 확인 방법 포함)
- 제외한 문헌 목록과 사유
- CVE-2026-2673 분석 노트

## 완료 기준

- 실험·데이터로 검증된 연구가 하나 이상 목록에 있다.
- 알려진 사실과 새 주장이 구분되어 있다.
- 모든 문헌이 실존 검증을 거쳤고 확인 방법이 적혀 있다.

## 주의

- AI가 제시한 문헌은 할루시네이션 가능성이 있으므로 반드시 실물을 직접 확인한다.
- 숫자와 결론은 원문에서 직접 확인한다 (요약·번역만 AI에게 맡김).
