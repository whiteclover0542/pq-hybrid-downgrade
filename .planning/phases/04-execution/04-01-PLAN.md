# Phase 4 실험 실행 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Phase 3에서 검증된 결함 주입 도구로, 실행 설계를 먼저 고정한 뒤 구현체(3)×결함유형(2) = 6조합을 조합당 최소 10회 반복 실행하고, 모든 실행의 원시 데이터(로그·pcap·프록시 로그·JSON)를 삭제 없이 보존한다. 실행 중 설계 변경은 시점·내용·이유와 함께 기록한다.

**Architecture:** Phase 3 러너(`tools/faultinject/run.py`)에 반복 실행 기능(`--repeat N`)과 실행 전 환경 프리플라이트를 추가한다. 반복 실행은 각 조합에 `r01`~`rNN` 반복 번호를 붙여 `docs/research/baselines/raw/phase-4/`에 기록한다(Phase 3 스모크와 분리). 실행 후 집계기(`aggregate.py`)가 모든 JSON을 읽어 조합별 실행 수와 `manipulation_verified` 분포를 매니페스트로 만들고, 설계된 표본 크기(조합당 ≥10 검증 실행)를 충족하는지 판정한다. 변인은 구현체×결함유형뿐이고 나머지(하이브리드 그룹 설정·loopback 네트워크·감사/로깅 경로)는 Phase 2/3과 동일하게 고정한다.

**Tech Stack:** Phase 3 도구 그대로(Python 3 표준 라이브러리 + `tshark`), Phase 2 빌드 바이너리, WSL2 Ubuntu.

**Spec:** `.planning/REQUIREMENTS.md`의 `REQ-repeated-execution`, `.planning/ROADMAP.md` Phase 4 성공 기준, `docs/research/phase-3-experiment-design.md`(변수·기준값·주입 지점·원시 데이터 규칙), `.planning/phases/03-tooling/03-01-SUMMARY.md`의 Phase 4 인계 조건.

## Global Constraints

- **선(先)설계 고정**: 반복 실행을 시작하기 전에 표본 크기·변인·고정 요인·파일명 규칙을 `docs/research/phase-4-execution.md`에 고정한다. 실행 시작 후의 설계 변경은 그 문서의 변경 로그에 시점·내용·이유로만 기록하고, 기존 원시 데이터는 삭제·수정하지 않는다.
- **변인/고정**: 변인 = 구현체(3)×결함유형(2). 고정 = 하이브리드 그룹 설정, loopback 네트워크, 감사/로깅 경로, 실행 조건(`condition=default`).
- **표본 크기**: 조합당 최소 10회 `manipulation_verified=true` 실행. 검증 실패 실행이 나오면 그만큼 더 돌려 검증 실행 수가 10을 넘게 하되, 실패 실행도 보존한다.
- **Phase 2 환경 고정**: `run.py`가 쓰는 절대 경로 바이너리·`LD_LIBRARY_PATH`·`OPENSSL_MODULES`·KEX 강제 옵션은 Phase 2 대장 값 그대로다. 실행 전 프리플라이트로 provider/그룹 로딩을 재확인한다.
- **원시 데이터 보존**: 파일명은 `<impl>_<fault>_r<NN>_<condition>`. 모든 실행의 로그·pcap·프록시 로그·JSON을 `raw/phase-4/`에 보존하고 사전 삭제하지 않는다.
- **재현 가능성**: `docs/research/phase-4-execution.md`에 제3자가 같은 순서로 재현할 수 있는 명령·전제·표본 크기를 적는다.

## Review Focus

- 반복 번호가 겹치거나 빠지지 않는가 — 각 조합이 `r01`~`rNN`을 정확히 한 번씩 갖는지 집계기로 확인한다.
- 검증 실패 실행을 표본에 넣어 결론을 왜곡하지 않는가 — 표본 수 판정은 `manipulation_verified=true`만 센다. 실패 실행은 보존하되 분리한다.
- 60회 배치 도중 환경이 바뀌어 일부만 시스템 바이너리로 실행되지 않는가 — 프리플라이트를 배치 시작 시 1회, 그리고 각 실행 로그에 바이너리 경로가 남는지 확인한다.
- 원시 데이터 개수가 설계 표본과 일치하는가 — 집계기가 조합별 총/검증 실행 수를 세고 설계값과 대조한다.
- 실행 중 설계를 바꿨는데 로그에 안 남기지 않는가 — 변경 로그가 비어 있으면 "변경 없음"을 명시한다.

```python
from faultinject.aggregate import aggregate, meets_minimum

def _write(dir, impl, fault, rep, verified, group, result):
    rid = run_id(impl, fault, rep, "default")
    RunRecord(rid, impl, fault, rep, "default",
              Metrics(group, group is not None and group.startswith("X25519ML"),
```

```python
# tools/faultinject/aggregate.py
from __future__ import annotations
import csv, sys
from pathlib import Path
from faultinject.record import RunRecord

def aggregate(run_dir) -> dict:
    counts: dict = {}
    for p in sorted(Path(run_dir).glob("*.json")):
        r = RunRecord.from_json(p)
        c = counts.setdefault((r.implementation, r.fault_type),
                              {"total": 0, "verified": 0, "success": 0, "downgrade": 0})
        c["total"] += 1
        if r.manipulation_verified:
            c["verified"] += 1
        if r.metrics.handshake_result == "success":
            c["success"] += 1
        if r.metrics.downgrade_visible:
            c["downgrade"] += 1
    return counts

def meets_minimum(counts: dict, minimum: int = 10) -> bool:
    return len(counts) == 6 and all(c["verified"] >= minimum for c in counts.values())

def write_manifest(run_dir, out_csv=None) -> Path:
    run_dir = Path(run_dir)
    out_csv = Path(out_csv) if out_csv else run_dir / "manifest.csv"
    counts = aggregate(run_dir)
    with out_csv.open("w", newline="", encoding="utf-8") as f:
        w = csv.writer(f)
        w.writerow(["implementation", "fault_type", "total", "verified", "success", "downgrade"])
        for (impl, fault), c in sorted(counts.items()):
            w.writerow([impl, fault, c["total"], c["verified"], c["success"], c["downgrade"]])
    return out_csv

def main(argv=None) -> int:
    run_dir = Path(__file__).resolve().parents[2] / "docs/research/baselines/raw/phase-4"
    counts = aggregate(run_dir)
    path = write_manifest(run_dir)
    ok = meets_minimum(counts)
    print(f"manifest: {path}")
    for (impl, fault), c in sorted(counts.items()):
        print(f"  {impl}/{fault}: total={c['total']} verified={c['verified']} "
              f"success={c['success']} downgrade={c['downgrade']}")
    print("sample size OK" if ok else "sample size NOT met (need >=10 verified per combo)")
    return 0 if ok else 1

if __name__ == "__main__":
    sys.exit(main())
```
