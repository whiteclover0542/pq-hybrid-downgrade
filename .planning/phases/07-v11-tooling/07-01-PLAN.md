# v1.1 Phase 1 (도구 확장) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 기존 `tools/faultinject/` 도구를 확장해, v1.1 설계의 새 협상 조건(`base`, `silent-downgrade`, `onpath-strip`, `ssh-order`)과 새 지표(HRR 발생 여부, 감사 가시성, 하이브리드 광고 여부)를 실행·기록할 수 있게 한다. 새 실험은 이 Phase에서 돌리지 않는다(P2에서 실행) — 여기서는 도구와 단위 테스트만 완성한다.

**Architecture:** v1.0 도구를 재작성하지 않고 확장한다. `Metrics`에 필드를 추가(하위 호환), 새 조건 빌더 `conditions.py`를 추가(silent-downgrade는 TLS 그룹 순서 설정만 — 주입 불필요), `harness.py`에 HRR·감사 가시성 파서를 추가, `tls_clienthello.py`에 on-path 스트리핑 mutate를 추가(기존 binding 조작과 공존). 판정 근거는 2026-09-23 스파이크(OpenSSL/BoringSSL 모두 하이브리드 광고+고전 key_share → HRR 없이 고전 협상; ServerHello 크기 하이브리드 ~0x04ba vs 고전 ~0x007a).

**Tech Stack:** Python 3(표준 라이브러리), 기존 faultinject 모듈, Windows Python 3.11에서 단위 테스트(실행 검증은 P2에서 WSL).

**Spec:** `docs/research/2026-09-23-v1.1-hrr-downgrade-design.md` (§4 실험 설계, §5 도구 변경, §9 정직성 제약).

## Global Constraints

- **하위 호환**: `Metrics`/`RunRecord`의 기존 JSON(v1.0 phase-3/phase-4)이 `from_json`으로 계속 읽혀야 한다. 새 필드는 기본값을 가진다.
- **정직성**: 새 지표는 설계 §4.3의 조작적 정의만 구현한다. "silent"은 감사 가시성(§4.3-4)의 bool로만; "HRR 부재"는 관측일 뿐 "버그"로 라벨링하지 않는다.
- **재작성 금지**: v1.0 도구(`fault_binding`, `verify_applied`, `run`의 smoke/phase4 경로, 기존 테스트)를 깨지 않는다. 기존 6개 phase-4 조합 테스트가 계속 통과해야 한다.
- **TLS 조건은 설정, 주입 아님**: `silent-downgrade`는 클라이언트 `-groups 고전:하이브리드` + 서버 `-groups 하이브리드:고전`으로 만든다. MITM 프록시는 `onpath-strip`(A)에만 쓴다.
- **테스트는 결정적**: HRR/그룹 판정 파서는 스파이크에서 얻은 실제 문자열·크기나 합성 픽스처로 검증한다. WSL 실행 의존 테스트는 만들지 않는다.

## Review Focus

- `Metrics` 확장이 기존 JSON을 깨지 않는가 — v1.0 phase-4 JSON 하나를 `from_json`으로 읽는 테스트로 확인.
- `silent-downgrade` 조건이 실제로 "하이브리드 광고 + 고전 key_share 우선"을 만드는가 — 클라이언트 명령의 `-groups` 값이 `고전:하이브리드` 순서인지.
- HRR 파서가 "ServerHello 1개=HRR 없음"과 "HelloRetryRequest 존재"를 정확히 구분하는가 — 스파이크 로그 형식 기준.
- 그룹 판정이 `<NULL>` 조기종료를 오판하지 않는가 — ServerHello 크기 폴백(하이브리드 vs 고전)이 있는가.
- on-path 스트리핑이 하이브리드 KeyShareEntry와 supported_groups의 하이브리드 항목을 모두 제거하는가(둘 중 하나만 제거하면 조작 불완전).
- 기존 `--smoke`/`--repeat`(phase-4) 경로가 그대로 동작하는가.

- [ ] **Step 3: 파서를 구현한다**

  `harness.py`에 추가한다. ServerHello 크기는 `-msg`의 `Handshake [length XXXX], ServerHello`에서 16진 길이를 읽어 0x0400(1024) 이상이면 하이브리드로 본다(스파이크: 하이브리드 0x04ba, 고전 0x007a). `detect_hrr`은 `HelloRetryRequest` 문자열 존재로 판정. `audit_flags_downgrade`는 설계 §4.3-4의 정의대로 표준 감사가 광고-협상 불일치를 자동 표면화하지 않음을 반영해 항상 `False`(=silent)를 반환하되, 시그니처로 "다운그레이드 발생 자체"는 호출부가 `advertised_hybrid and not negotiated_is_hybrid`로 별도 계산한다.

```python
import re as _re

def detect_hrr(client_log_text: str) -> bool:
    return "HelloRetryRequest" in client_log_text

def server_hello_is_hybrid(client_log_text: str) -> bool | None:
    m = _re.search(r"Handshake \[length ([0-9a-fA-F]+)\], ServerHello", client_log_text)
    if not m:
        return None
    return int(m.group(1), 16) >= 0x0400

def audit_flags_downgrade(advertised_hybrid: bool, negotiated_is_hybrid: bool) -> bool:
    # Operational def (§4.3-4): standard audit tools do NOT auto-surface an
    # advertised-hybrid vs negotiated-classical mismatch. A human must diff. -> silent.
    return False

def collect_metrics_v11(impl, client_log_text, exit_code, advertised_hybrid):
    base = collect_metrics(impl, client_log_text, exit_code)
    # group-name parse can be <NULL> on early close -> fall back to ServerHello size
    if base.negotiated_group is None:
        sh_hybrid = server_hello_is_hybrid(client_log_text)
        if sh_hybrid is not None:
            base.is_hybrid = sh_hybrid
            base.downgrade_visible = not sh_hybrid
    base.hrr_present = detect_hrr(client_log_text)
    base.advertised_hybrid = advertised_hybrid
    base.downgrade_flagged = audit_flags_downgrade(advertised_hybrid, base.is_hybrid)
    return base
```

**Interfaces:**

- Produces: `verify_applied.py`의 `verify_condition(record, ...)` — silent-downgrade는 pcap ClientHello에 하이브리드가 광고됐고 고전 key_share가 전송됐는지, onpath-strip은 프록시 로그의 제거 적용을 확인.

- [ ] **Step 1: 실패 테스트를 쓴다 (조합 수·조건 커버리지)**

```python
# tools/faultinject/tests/test_v11_runner.py
from pathlib import Path
from faultinject.run import v11_specs

def test_v11_covers_conditions():
    specs = v11_specs(1, output_dir=Path("/tmp/v11"))
    combos = {(s.impl, s.condition) for s in specs}
    assert ("openssl", "silent-downgrade") in combos
    assert ("boringssl", "silent-downgrade") in combos
    assert ("openssh", "ssh-order") in combos
    assert ("openssl", "base") in combos
    # silent-downgrade only for the two TLS impls (SSH has no key_share/HRR)
    assert ("openssh", "silent-downgrade") not in combos

def test_v11_reps_scale():
    one = len(v11_specs(1, output_dir=Path("/tmp/v11")))
    ten = len(v11_specs(10, output_dir=Path("/tmp/v11")))
    assert ten == one * 10
```
